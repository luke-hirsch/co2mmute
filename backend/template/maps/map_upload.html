So ist die JSON-Datei aufgebaut

Die Datei beschreibt einen Graphen aus Knoten und Kanten. Die Schlüssel selbst bleiben englisch — das sind die Feldnamen der Karte: 

{
  "nodes": [
    {
      "id": "A",
      "x": 0.0,
      "y": 0.0,
      "name": "Bahnhof Mitte",
      "types": ["intersection", "station"]
    },
    {
      "id": "B",
      "x": 5.0,
      "y": 3.5,
      "name": "Wohnort 1",
      "types": ["home"]
    }
  ],
  "edges": [
    {
      "start_node": "A",
      "end_node": "B",
      "name": "Hauptstraße",
      "type": "street",
      "biking": true,
      "walking": true,
      "speed_limit": 50,
      "lanes": 2,
      "dedicated_bus_lane": false,
      "max_lanes": 2
    }
  ],
  "bus_lines": [
    {
      "name": "M1",
      "edges": [0],
      "interval": 5,
      "capacity": 85
    }
  ],
  "train_lines": [
    {
      "name": "S1",
      "edges": [0],
      "interval": 10,
      "capacity": 1000
    }
  ]
}

Pflichtfelder:

  • nodes: die Liste der Knoten
  • edges: die Liste der Kanten

Pflichtfelder eines Knotens:

  • id: eindeutige Kennung (Text oder Zahl)
  • x: x-Koordinate (Zahl)
  • y: y-Koordinate (Zahl)

Optionale Felder eines Knotens:

  • name: der angezeigte Name (sonst die id)
  • types: die Arten des Knotens, z. B. "home", "workplace", "intersection", "bus_stop", "station"

Pflichtfelder einer Kante:

  • start_node: die id des Startknotens
  • end_node: die id des Zielknotens

Optionale Felder einer Kante:

  • name: der angezeigte Name
  • type: "street", "train", "both" oder "path" (Vorgabe: "both")
  • biking: ob Räder hier fahren dürfen (Vorgabe: true)
  • walking: ob Fußgänger hier gehen dürfen (Vorgabe: true)
  • speed_limit: Tempolimit in km/h (Vorgabe: 50)
  • lanes: Zahl der Spuren, Busspur eingeschlossen (Vorgabe: 1)
  • dedicated_bus_lane: eigene Busspur, nimmt eine Spur weg (Vorgabe: false)
  • max_lanes: wie viele Spuren die Straße höchstens haben kann (Vorgabe: 2)

Optionale Felder einer Buslinie:

  • name: der Name der Linie, z. B. "M1", "100"
  • edges: die Nummern der Kanten, über die die Linie fährt
  • interval: der Takt in Minuten (Vorgabe: 5)
  • capacity: Plätze im Bus (Vorgabe: 85)

Optionale Felder einer Bahnlinie:

  • name: der Name der Linie, z. B. "S1", "U6"
  • edges: die Nummern der Kanten, über die die Linie fährt
  • interval: der Takt in Minuten (Vorgabe: 10)
  • capacity: Plätze in der Bahn (Vorgabe: 1000)
