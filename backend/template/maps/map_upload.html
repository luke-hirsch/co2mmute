JSON Format Requirements

Your JSON file should contain a graph structure with nodes and edges: 

{
  "nodes": [
    {
      "id": "A",
      "x": 0.0,
      "y": 0.0,
      "name": "Downtown Station",
      "types": ["intersection", "station"]
    },
    {
      "id": "B",
      "x": 5.0,
      "y": 3.5,
      "name": "Home Area",
      "types": ["home"]
    }
  ],
  "edges": [
    {
      "start_node": "A",
      "end_node": "B",
      "name": "Main Street",
      "type": "street",
      "biking": true,
      "walking": true,
      "speed_limit": 50,
      "lanes": 2,
      "dedicated_bus_lane": false,
      "max_lanes": 2
    }
  ],
  "bus_lines": [
    {
      "name": "M1",
      "edges": [0],
      "interval": 5,
      "capacity": 60
    }
  ],
  "train_lines": [
    {
      "name": "S1",
      "edges": [0],
      "interval": 10,
      "capacity": 500
    }
  ]
}

Required fields:

  • nodes: List of node objects
  • edges: List of edge objects

Node required fields:

  • id: Unique identifier (string or number)
  • x: X coordinate (number)
  • y: Y coordinate (number)

Node optional fields:

  • name: Display name (defaults to id)
  • types: Array of node type names (e.g., "home", "workplace", "intersection", "bus_stop", "station")

Edge required fields:

  • start_node: ID of start node
  • end_node: ID of end node

Edge optional fields:

  • name: Display name
  • type: "street", "train", or "both" (default: "both")
  • biking: Boolean for street usage (default: true)
  • walking: Boolean for street usage (default: true)
  • speed_limit: Speed limit in km/h (default: 50)
  • lanes: Number of lanes (default: 1)
  • dedicated_bus_lane: Boolean (default: false)
  • max_lanes: Maximum number of lanes (default: 2)

BusLine optional fields:

  • name: Bus line name (e.g., "M1", "12")
  • edges: Array of edge indices that form the bus line
  • interval: Departure interval in minutes (default: 5)
  • capacity: Bus passenger capacity (default: 60)

TrainLine optional fields:

  • name: Train line name (e.g., "S1", "U6")
  • edges: Array of edge indices that form the train line
  • interval: Departure interval in minutes (default: 10)
  • capacity: Train passenger capacity (default: 500)
